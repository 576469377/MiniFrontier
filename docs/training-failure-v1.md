# educational-v1 对话训练失败复盘（2026-09-08）

本轮目标是训练能进行基本对话的模型并提供 Demo，结果失败。三个模型均完成训练和导出，但 SFT 输出仍重复、偏题；DPO 后对话 NLL 进一步恶化。主要已知问题是训练覆盖不足、前缀采样偏置和生成验证缺失。

以下记录对应 2026-09-08，当前四模型训练安排见[预训练计划](pretraining-plan.md)。

## 实测证据

复查使用完整 **551 条 SFT 留出样本、75,084 个监督 token** 和 **172 对偏好留出样本**。SFT/DPO 检查点在同一对话集计算 token 加权 NLL，另对四条固定提示做 greedy 生成；报告保留输出、权重 SHA256 和结束时间。

| 模型 | SFT 对话 NLL | DPO 对话 NLL | 生成观察 |
|---|---:|---:|---|
| MiniKimi-K3 | 6.868 | 7.462 | SFT 不连贯，反复生成无关内容 |
| MiniDeepSeek-V4 | 6.625 | 7.392 | SFT 不连贯，DPO 后 NLL 继续恶化 |
| MiniQwen4 | 6.453 | 8.041 | SFT 重复错误算式，DPO greedy 输出连续换行 |

172 对偏好验证的 DPO loss，按 Kimi/DeepSeek/Qwen 顺序为 **0.912 / 1.134 / 1.305**，margin 正确率为 **62.8% / 61.6% / 53.5%**。这些偏好指标没有反映出可用的对话质量。

完整证据：[Kimi](audits/minikimik3-capability-v1.json)、[DeepSeek](audits/minideepseekv4-capability-v1.json)、[Qwen](audits/miniqwen4-capability-v1.json)。

例如 Kimi SFT 对“请解释为什么下雨后地面会湿。”反复输出“意识”；Qwen SFT 对“2 加 3 等于几”反复生成错误算式。问题在 DPO 前已存在。

## 已确认的方案缺陷

1. **训练覆盖不足。** 每模型基础预训练仅 `1000 × 8 × 255 = 2,040,000` 个预测 token，约为现有预训练数据的 0.267 轮；Qwen/DeepSeek 另有约 164 万继续预训练 token。SFT 只消费 4,000 条样本，约 0.136 轮；DPO 只消费 800 对。阶段按步数自动推进，没有先检查生成结果。
2. **前缀采样有明显模板偏置。** 29,449 条 SFT 训练记录只有 11,865 种首个用户问题。其中“你今天过得怎么样？”出现 2,230 次，“你如何看待自身存在的目的与意义？”1,006 次，“你如何看待自我意识的边界？”599 次。取文件前缀后 shuffle，以及整段 JSON 精确去重，均未消除这些重复开头。
3. **验证样本不足且有位置偏置。** 每 rank 只看文件开头 4 条，共 8 条；开头又集中于身份类对话。这使训练期验证难以代表完整留出集。
4. **过早进入 DPO。** SFT 尚未通过生成检查就启动偏好训练，Demo 又默认选择最新阶段；本次 DPO 检查点的对话 NLL 全部更差。
5. **模型容量与数据预算缺乏配套评估。** 65,536 词表的输入 embedding 和独立输出头合计约 6,711 万参数。缩小层数后仍需要检查词表成本与训练覆盖，相关实践可参考 [MiniMind tokenizer 说明](https://github.com/jingyaogong/minimind#ⅰ-tokenizer)。

长度 256 还截断了 **4,597 / 29,449 条 SFT 对话（15.6%）**。抽查中 tokenizer 往返、角色边界、assistant 标签与推理前缀能够对齐；这项检查不足以排除其他整模型实现问题。

## 已落实的纠正

| 修正 | 当时落实情况 |
|---|---|
| 数据采样 | 新入口默认对固定 revision 完整文件做 reservoir 抽样，记录文件 hash、原始行数与 seed；旧数据尚未按新方式重建 |
| 验证 | 整个留出集上固定均匀取样，默认每 rank 64 条，`--eval-batches 0` 覆盖全量 |
| 预算 | 预训练/SFT 显式指定步数或 epoch，记录覆盖量；移除隐式 1,000/500 步配置，DPO 默认关闭 |
| 检查点评估 | 完整留出 NLL、偏好指标与固定生成分别报告；运行完成状态与能力状态分开 |
| Demo | 默认 SFT，提供 SFT/DPO 切换，并显示未通过对话检查 |

## 尚未完成

记录时没有得到新的可用对话模型，也没有启动第二轮长训练。另开小型记忆实验：各模型从自身 SFT 权重出发，训练 8 个短问答、100 次更新、长度 64，训练与验证故意使用相同数据。

[Kimi](audits/minikimik3-memorization-v1.json) 与 [DeepSeek](audits/minideepseekv4-memorization-v1.json) 已完成，greedy 复述均为 **8/8**，记忆 NLL 分别为 **0.000448 / 0.000222**。Qwen 当时只记录到第 25 步，NLL **0.00629**，尚无最终生成结果。产物位于 `outputs/<model>/memorization-probe-v1/`，用途为 `acceptance`。

记忆实验说明基础训练与生成链路可以拟合少量样本；下一轮仍需重做语料覆盖、模板去重、完整回复、词表和 token 预算的设计，并在 SFT 生成有实质改善后再评估偏好训练。

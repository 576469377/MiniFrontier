# v0.1.0 研究预览版

v0.1.0 提供 [MiniFrontier1.0](../models/minifrontier1.md) 与三个来源模型的实现、离线训练示例、训练和推理工具，以及测试与实验记录。完整基础预训练、能力评估和公开权重尚未完成。本页说明发布范围，实际发布状态以 [GitHub Releases](https://github.com/576469377/MiniFrontier/releases) 为准。

## 分发支持范围

| 操作 | Git checkout / editable install | wheel |
|---|---|---|
| models、三个来源模型的 quickstart 与 MF1 quickstart、显式配置 acceptance 训练、显式 checkpoint CLI 生成 | 支持 | 支持，四模型示例单独在 checkout 外验收 |
| 原始源码 oracle、项目测试、数据研究与调度脚本 | 支持 | 不包含完整开发资源；使用 checkout |
| 正式策略检查与训练 | 需要干净且可追溯的 Git 源码、原策略正文、数据与前驱证据 | 首版不支持；入口报告需要 Git checkout |
| 默认浏览器体验 | 需要独立验收后的权重 | 同样需要独立权重；包内不附带模型 |
| 显式诊断浏览器 | 来源模型用 `--include-experiments`；MF1 用 `--allow-unqualified` | 使用已有本地检查点；诊断模式不授予能力资格 |

sdist 包含开发和研究材料，但解包后没有 Git 身份，也不保证覆盖文档引用的全部历史附件。正式训练及完整文档复现使用 Git checkout。wheel 中的策略 JSON 是参考资源，不能代替方案正文、源码身份与数据证据；安装方式见[最小示例](../guides/quickstart.md)。

## 路线图

1. 按[主计划](../pretraining-plan.md)完成四模型基础预训练及索引器阶段，补齐后续数据并持续固定验证。
2. 完成基础模型评估，再推进教师资格、后训练、RL 和草稿速度评估；DeepSeek 视觉扩展单列预算。
3. 发布权重时附[模型卡](../../MODEL_CARD_TEMPLATE.md)、tokenizer、配置、校验值、评估与产物许可。
4. 完善安装包资源、浏览器体验和私密反馈渠道；发布前逐项检查分发内容与文档链接。

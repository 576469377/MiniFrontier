# v0.1.0 研究预览版

v0.1.0 研究预览代码覆盖 MF1.0、MF1.1、MiniKimi-K3、MiniQwen4、MiniDeepSeek-V4 和 MiniDeepSeek-V4.1 六个版本，提供模型实现、训练和推理工具、离线示例及实验记录。模型清单见[模型索引](../README.md#模型结构与阅读顺序)。完整基础预训练、能力评估和公开权重尚未完成；实际发布状态以 [GitHub Releases](https://github.com/576469377/MiniFrontier/releases) 为准。

## 能力状态

| 范围 | 已实现 | 已验证 | 已训练／待完成 |
|---|---|---|---|
| MF1.0 | 原生多模态 decoder 与独立 `mf1` 流程 | CPU 数值、完整配置前后向、恢复、媒体、草稿与历史 wheel 验收；CUDA 短程更新及部分性能测量 | 正式预训练进行中，能力评估待完成 |
| MF1.1 | 独立模型包，保留 MF1.0 媒体协议；使用 Single-Pass mHC 与 Muon / Sinkhorn，关闭 MTP | CPU 公式、梯度、因果性、媒体缓存、数据复用、恢复、导出及离线阶段流程 | 独立随机初始化的正式预训练已启动；草稿模型未实现 |
| Kimi / Qwen / DeepSeek-V4 | 来源架构适配、训练与推理入口 | 源码组件、梯度、因果性、CPU/DDP；覆盖范围见模型页 | 正式预训练进行中，完整主训练待完成 |
| DeepSeek-V4.1 | CED、CSA2、Engram、Single-Pass mHC 与纯文本稀疏预训练 | CPU 公式、共享状态、梯度、因果性、优化器和前缀重算缓存 | 正式文本预训练已启动；视觉模块有测试，完整视觉数据、迁移与推理流程尚未接通 |
| 原生视觉与 MTP | Kimi / Qwen / MF1.0 支持视觉与 MTP；MF1.1 支持视觉、无 MTP；V4 视觉扩展独立接续 | 短流程、数值、媒体梯度和掩码测试 | 独立视觉能力与后续分布评估待完成；模块存在不表示当前权重已学会使用 |
| 优化器与路由更新 | 各来源模型及 MF1 的专用实现 | 数值、参数分组、更新与恢复测试 | 长期稳定性随各版本正式训练记录 |
| Kimi / DeepSeek QAT 数值仿真 | 是 | 数值与更新测试 | 尚无训练后量化部署结果；Qwen 未声明该配方 |
| 缓存与草稿路径 | 旧四模型有缓存与草稿；MF1.1 复用原生缓存、无草稿；V4.1 每步重算前缀 | 按各模型支持范围检查一致性、接受/拒绝和回滚 | 未获得训练后加速结论；V4.1 当前缓存不提供增量 KV 加速 |
| 工具 rollout、GRPO/MOPD/OPD | 是 | 工程和可核验任务测试 | Kimi 9 教师、DeepSeek 12 教师与 MF1 8 个领域/模式槽的资格、正式 RL 预算均待完成 |
| 浏览器 Demo | 六版本文本比较页；MF1.0 / MF1.1 共用独立图片与视频页面 | 权重发现、版本绑定、输入模板、媒体预算与 API 检查 | 正式训练视图可展示已保存但尚未验收的权重；无通过能力验收的聊天权重 |

上表更新于 2026-09-14。各版本当前阶段和训练记录统一见[主计划](../pretraining-plan.md)，历史测试按各自时间、源码和配置阅读。

“已实现”是代码存在；“已验证”必须有对应范围的检查；“已训练”只描述实际预算和数据，不自动表示具备能力。模型清单的 `training_ready` 表示训练入口可执行，需结合 `training_ready_scope` 和 `usable_chat_checkpoint` 阅读。

## 分发支持范围

| 操作 | Git checkout / editable install | wheel |
|---|---|---|
| 模型清单与显式 checkpoint CLI 生成 | 支持六版本；MF1 原生媒体使用 `mf1 generate` | 包含六版本代码与配置，不附权重；新版本的检查范围见上表 |
| 通用 quickstart 与 MF1.0 quickstart | 通用入口覆盖 Kimi / Qwen / DeepSeek-V4；MF1 使用独立 `mf1` 入口 | 旧四模型示例曾在 checkout 外验收，该历史记录不覆盖新增版本 |
| MF1.1 quickstart 与训练 | `mf1 quickstart --model-version 1.1`；训练绑定独立版本方案 | 当前需要 Git checkout 中的版本方案，不能只依赖 wheel |
| 原始源码 oracle、项目测试、数据研究与调度脚本 | 支持 | 不包含完整开发资源；使用 checkout |
| 正式策略检查与训练 | 需要干净且可追溯的 Git 源码、原策略正文、数据与前驱证据 | 首版不支持；入口报告需要 Git checkout |
| 默认文本 Demo | 正式训练视图展示已保存的 `strategy` 检查点，允许尚未通过能力验收的权重 | 使用本地已有检查点和运行元数据 |
| 更多实验与媒体诊断 | 文本页用 `--include-experiments` 开放短程和历史实验；MF1 媒体页用 `--allow-unqualified` | 使用已有本地产物；展示和生成均不授予能力资格 |

sdist 包含开发和研究材料，但解包后没有 Git 身份，也不保证覆盖文档引用的全部历史附件。正式训练及完整文档复现使用 Git checkout。wheel 中的策略 JSON 是参考资源，不能代替方案正文、源码身份与数据证据；安装方式见[最小示例](../guides/quickstart.md)。

## 路线图

1. 按[主计划](../pretraining-plan.md)分别推进六版本基础预训练及各自索引器安排，补齐后续数据并持续固定验证。
2. 完成基础模型评估，再推进教师资格、后训练和 RL；草稿与视觉接续按各版本实际支持范围实施并独立评估。
3. 发布权重时附[模型卡](../../MODEL_CARD_TEMPLATE.md)、tokenizer、配置、校验值、评估与产物许可。
4. 完善安装包资源、浏览器体验和私密反馈渠道；发布前逐项检查分发内容与文档链接。

本地检查范围记录在[早期三模型预览验收记录](preview-validation.json)与[后续 MF1 验收记录](../audits/minifrontier1-validation.json)，均按各自时间与源码版本阅读；最小示例的实际输出另存于实验档案。CI 配置覆盖 Python 3.11/3.13 的静态检查、CPU/Gloo、构建和安装包验收；每次提交的实际执行结果见 [GitHub Actions](https://github.com/576469377/MiniFrontier/actions)。

# v0.1.0 研究预览版

本页定义 v0.1.0 的研究预览范围。仓库提供源码与实验记录，尚无通过能力评估的公开模型权重。

首版提供三条来源可追溯的对照架构，以及融合主线 [MiniFrontier1.0](../models/minifrontier1.md)、离线微型训练示例、训练与推理工具、源码对照测试和轻量实验档案。完整数十亿 token 主训练、经过验收的聊天/视觉模型、多教师正式后训练及草稿加速结果属于后续工作。

## 分发支持范围

| 操作 | Git checkout / editable install | wheel |
|---|---|---|
| models、三个来源模型的 quickstart 与 MF1 quickstart、显式配置 acceptance 训练、显式 checkpoint CLI 生成 | 支持 | 支持，四模型示例单独在 checkout 外验收 |
| 原始源码 oracle、项目测试、数据研究与调度脚本 | 支持 | 不包含完整开发资源；使用 checkout |
| 正式策略检查与训练 | 需要干净且可追溯的 Git 源码、原策略正文、数据与前驱证据 | 首版不支持；入口报告需要 Git checkout |
| 默认浏览器体验 | 需要独立验收后的权重 | 同样需要独立权重；包内不附带模型 |
| 显式诊断浏览器 | 来源模型用 `--include-experiments`；MF1 用 `--allow-unqualified` | 使用已有本地检查点；诊断模式不授予能力资格 |

sdist 保留开发资源与历史研究材料，但解包的 sdist 本身没有 Git 身份，也不自动满足正式策略训练。wheel 中的策略 JSON 仅为参考资源，不能单独代替方案正文与 Git 证据。完整训练请从正式仓库 checkout 后 `uv sync --locked` 或 editable install。

## 路线图

1. 按[预训练主计划](../pretraining-plan.md)推进四个模型已启动的首阶段，记录固定验证结果，并准备后续阶段数据。已有对照的[参数选择依据](../experiments/2026-09-10-pretraining-cutover/working-recipes.md)保留供复现。
2. 从零完成 Kimi 2B、Qwen 3B、DeepSeek 文本 2.5B、MF1 3B CE 的基础预训练及必要索引器阶段，分别评估、导出；DeepSeek 视觉扩展另列后续预算。
3. 完成合格教师、多教师后训练、正式 RL 及目标绑定的草稿训练/速度评估。
4. 发布权重时提供完整模型卡、tokenizer、配置、校验值、能力评估、局限与产物许可。
5. 扩展 wheel 的正式策略资源支持及更完整的浏览器体验。

实验材料包含失败和未完成结果；权重发布另需能力评估。

本地检查范围记录在[早期三模型预览验收记录](preview-validation.json)与[后续 MF1 验收记录](../audits/minifrontier1-validation.json)，均按各自时间与源码版本阅读；最小示例的实际输出另存于实验档案。CI 配置覆盖 Python 3.11/3.13 的静态检查、CPU/Gloo、构建和安装包验收；每次提交的实际执行结果见 [GitHub Actions](https://github.com/576469377/MiniFrontier/actions)。

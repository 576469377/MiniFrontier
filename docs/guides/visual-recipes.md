# 六个模型的视觉训练起点

训练一个视觉编码器有两次需要记录的初始化。第一处是视觉塔本身的第一个训练步；第二处是它接入最终语言主干的那一步。Kimi K3 在同一轮训练里完成这两件事。DeepSeek-V4.1 先单独训塔，再把训好的塔接到最终主干。复现实验应记录两处的权重来源。

| 本仓模型 | 上游视觉塔与主干的训练顺序 | 本仓已运行的路线 |
|---|---|---|
| MiniKimi-K3 | Kimi K3 将随机初始化的 MoonViT-V2、轻量投影和语言主干从训练开始一起优化。图像、视频和文本共享下一 token 预测目标。报告用 SigLIP 初始化作了对照，最终选用从零训练的视觉塔。见[原报告 §2.4、§3.3](https://arxiv.org/pdf/2607.24653)。 | K1 从随机参数训练缩小的塔与主干，累计 20 万次图像曝光；K2 加入视频。 |
| MiniQwen4 | 固定的 `qwen4_exp` 对应 Qwen3.8-Flash-Next。发布配置含 27 层 ViT；报告描述语言主干持续预训练时由全局注意力转换为稀疏注意力。视觉塔初始权重、与主干对齐的日程及冻结策略在所查报告、模型卡中未披露。见[原报告](https://arxiv.org/abs/2608.30320)和[官方权重配置](https://huggingface.co/Qwen/Qwen3.8-Flash-Next/blob/812d96e10a0dd82b69d749e68693698cf6c36daa/config.json)。 | Q1 采用本地随机初始化图文联合训练，累计 30 万次图像曝光；Q2 加入视频。这是本项目选定的视觉训练路线。 |
| MiniDeepSeek-V4 | [V4 Flash/Pro 技术报告](https://arxiv.org/pdf/2606.19348v1)描述文本模型。另一个发布版本 **V4-Flash-Vision-Exp** 在 V4-Flash 架构上加入视觉模块后继续训练。官方披露了视觉塔与投影的推理实现，未说明塔最初的权重、冻结日程或所用视觉预训练量。见[固定版本的官方模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-Vision-Exp/blob/6821d6ad3681a4b137b066b76094fa82ebd0a380/README.md)。 | D1–D5 为文本主线，D3 蒸馏索引器，D4 与 D5 接着做稀疏预训练。单独的视觉实验配置对应 Vision-Exp。 |
| MiniDeepSeek-V4.1 | DeepSeek-V4.1-Flash 的 DeepSeek-ViT 最初从随机参数开始，先在约 470 亿图文对上做 SigLIP 对比训练，再接临时 4B MoE，在 2,360 亿 token 的描述、图表、OCR 等数据上做自回归训练。移除临时语言模型、保留训好的塔，再从最终主干训练开始接入图文数据。前期冻结塔主体，末端归一化和投影可训练；学习率衰减时以较小学习率解冻塔。主预训练总量为 45 万亿 token。见[原报告 §3、§4.1、§4.2.2](https://arxiv.org/pdf/2609.19969)。 | D1/D2 文本线与早期图文线各自保留。早期图文线同时随机初始化塔、投影与主干。新一轮先单训视觉塔，再接临时解码器，最后把视觉塔交给随机初始化的正式主干。各阶段的训练目标、曝光次数、监督 token 口径与可运行命令见[视觉课程](v41-vision-curriculum.md)。 |
| MiniFrontier1.0 | 本项目自研，塔、融合接口与训练课程由[MF1.0 模型说明](../models/minifrontier1.md)定义。 | P0 的初始权重记录为空，主干与塔从零联合训练。P1 加载本模型 P0 的训练权重。 |
| MiniFrontier1.1 | 本项目自研，保留 MF1.0 的视觉设计，修改残差和优化器。见[MF1.1 模型说明](../models/minifrontier11.md)。 | 独立初始化自己的 P0，P1 接续自己的 P0。两代模型分别维护权重。 |

## 怎样在小规模实验选路线

若目标是先取得可用的看图对话模型，可以先在纯文本上验证一个能接话、能结束的语言主干，接已有视觉塔后先学投影，再按需要联合微调。[MiniMind-V](https://github.com/jingyaogong/minimind-v)提供了这种路线的具体例子，使用已有语言底座和冻结的 SigLIP2。若目标是研究从零视觉学习，Kimi K3 提供了可对照的原型。比较路线时使用相同训练题、预算和留出图，分别记录正确图、换错图时的短答准确率，以及逐行 OCR 字符错误率。这样才能把「回复更流畅」与「回答随图而变」分别测出来。

## 测试条件

每份权重使用同一组 [32 条固定提示及参考续写](probes.json)，覆盖中文、英文、代码、数学、复制及结构化文本。主表比较 **BF16 autocast、开启缓存、最多 96 token、无重复惩罚**：

| 解码 | 参数 | 每份权重次数 |
|---|---|---:|
| 贪心 | Temperature 0，Top-p 1，seed 0 | 32 |
| 采样 | Temperature 0.7，Top-p 0.9，seed 0 / 17 / 42 | 96 |

另测原光合作用提示的 256-token 贪心续写、8 条提示的 48-token BF16 无缓存续写，以及 4 条提示各两种缓存条件的 FP32 续写，合计每份 145 次。这里的 FP32 指关闭 BF16 autocast，仍执行模型自身的算子；所有条件均关闭 TF32。

**严重重复**是自动启发式指标：相同 token 连续至少 8 次，或生成至少 24 token 且重复 4-gram 比例达到 50%。重复 4-gram 比例为 `1 − 不同四元组数 / 四元组总数`。此指标不是正确率，会漏掉换词重复、事实错误和跑题。

**参考 BPB**为 32 条固定参考续写的总负对数似然，除以 `ln(2) × 参考文本 UTF-8 字节数`；越低表示这些参考文本的预测损失越小。参考文本合计仅 **1,057 字节**，单独编码后接在提示 token 后。它用于同一模型内的定向对照，不是通用能力基准，也不适合作为跨模型排名。

## 中点与数值路径对照

1,885 条主测试输出中仅 3 条含中点 `·`，最长连续中点为 **1**。本轮没有出现整屏中点，但短语和句子循环大量存在。

36 次 8-token 采样器检查均与实际推理入口一致。对 4 份本轮最新权重，保存的 Demo / 训练源码之间 **48 组首步 logits 完全相同**；设置能够匹配的 **48 组生成前缀、共 2,304 token** 也完全相同。这些对照仅覆盖上述源码副本与所测输入。

缓存对照在每份权重上使用 4 条参考输入、两种精度，比较相同教师强制 token 下的整段计算与增量计算：

| 模型 | FP32 最大 logits 绝对差 | BF16 最大 logits 绝对差 |
|---|---:|---:|
| MiniDeepSeek-V4 | 0.0000176 | 2.191 |
| MiniKimi-K3 | **0.277** | 1.000 |
| MiniQwen4 | 0.0000420 | 0.406 |
| MF1.0 | **0.0117** | 1.031 |

FP32 的 780 个教师强制位置 top-1 全部一致，BF16 为 772/780；这不意味着 logits 数值完全等价。**Kimi 与 MF1 的 FP32 偏差仍需中间层定点检查**，不能直接归为普通舍入误差。

将生成统一截到 48 token 后，FP32 的 cache / no-cache 贪心前缀 **52/52 对相同**，BF16 为 86/104。FP32 且关闭缓存时，仍有 **39/52 次严重重复**。因此 BF16 或缓存不是这些循环出现的必要条件，但本轮不足以排除其他实现问题。

## 保存的失败样例

提示：`植物通过光合作用将光能转化为化学能。在这个过程中，`

DeepSeek D2 step 11600，BF16、开启缓存、贪心 256 token，输出开头：

> 植物的光能转化为化学能。植物的光能是光能转化为化学能的基础。植物的光能是光能转化为化学能的基础。

后一句持续循环。48-token FP32 无缓存对照也出现句子循环。

提示：`问题：1加1等于几？`，换行接 `答案：`。

| MF1 检查点 | 贪心 96-token 输出开头 | 后续 |
|---|---|---|
| P0 / 14599 | `2` | 无关编号与重复 |
| P1 / 13100 | `1加1=1` | 重复错误等式 |

这是单题失败与退步的证据，不能据此推断整体能力退化；它说明参考损失下降不等于回答正确。

本轮最新四份权重各 145 次主生成均未主动输出 EOS；全部 1,885 次主生成仅 1 次以 EOS 结束。续写无需短答即停，但结合循环现象，后续需要核对训练中 EOS 目标、loss mask 和文档边界的实际覆盖。推理动作屏蔽允许 EOS，不能仅凭输出断言训练已丢失 EOS。

<summary>1. 初始构造与恢复</summary>

### 2026-09-10：首批文本构造

首批目标按 64K 参考 tokenizer 计为中文 225M、英文 150M、OpenWebMath50M、对话 40M，共 465M 参考 token。构造器复用 Parquet 范围读取与 corpus 去重，按组划分 train/val/test 为 98.5%/0.5%/1%；重复文档的别名也连接到保留组，对话保留全部轮次。

首次在 **4,073 条、5,851,266 参考 token** 后中断：固定分片 `4_5/003932.parquet` 的一条 WuDao 记录 score 为 **1.0126953125**，超出 0–1 范围；该片 3,274 行的分数中位数约 0.817。修复将异常隔离并记录来源位置，保留原值和失败产物。

来源采用固定 revision，其中[OpenWebMath](https://huggingface.co/datasets/open-web-math/open-web-math/tree/fde8ef8de2300f5e778f56261843dab89f230815)的 ODC-BY、Common Crawl 及底层页面条款分别记录。单任务上限 12GiB，写入预留 80GiB。11 项 CPU 回归、Ruff 与模块 mypy 通过。

### MF1 紧凑二进制消费

`mf1 encode --compact` 按完整记录写 shard，默认约 64M input token/片。uint16 IDs 加监督位图约 **2.125 bytes/token**，替代原 ids/labels/三轴位置的 18 bytes/token；索引和媒体元数据另计，超过 65535 的 ID 使用 uint32。位置与模态按规则恢复，视觉塔仍处理原始像素。

最多打开四片 memmap，采样器从小索引建立长度/领域桶。7 项定向检查覆盖跨片文本/媒体、mask、位置、模型输出、损坏拒绝、uint32 与恢复；当时完整 CPU 为 **362 passed / 1 skipped**，其中常规 357 项、slow/distributed5 项，173 个源文件 mypy 及 Ruff/格式通过。旧 Qwen batch16 完成 20,016,632 CE，属于此前配方实验。

### 首批共享视觉候选与代码来源缺口

首批目标为自然图片 60K、文档 20K、图表 20K，同图最多保留 8 组完整问答；四项质量评分均≥3/5，最多扫描目标 4 倍的来源行。元数据/原图预算为 3/17GiB。

[ALLaVA-4V](https://huggingface.co/datasets/FreedomIntelligence/ALLaVA-4V)记录 CC-BY-NC-4.0 及底层图片限制；[CoSyn-400K](https://huggingface.co/datasets/allenai/CoSyn-400K)记录 ODC-BY-1.0 及生成内容条款。FineVision 包装层许可不覆盖各子来源。

首次视觉构造在目录请求中断，尚未读图；目录传输新增最多三次重试。代码来源另有缺口：6,756 条 Python-Edu 候选只有一条匹配 Apache 头，索引缺 license/revision_id；The Stack v2 访问返回 403，因此未使用这些记录补足代码域。

### 数据消费修复与空间回收

MF1 紧凑加载器改为按文件身份复用完整哈希检查，只读小索引与对应媒体偏移，解决随机跨片时反复扫描大文件的问题。相关 34 项通过，完整 CPU **370 passed / 1 skipped**；新增数据准备耗时、CE 比例和 padding 比例，见[性能审计](../../audits/minifrontier1-execution-performance.md)。

20 个已结束旧实验的优化器/RNG 检查点在核对依赖、权重与 tokenizer 后退役，释放 **51.58GiB**；保留推理权重及报告，另一个不满足条件的候选保留。逐项凭据见[检查点退役记录](checkpoint-retirement.json)。

### 工作配方选择与来源模型阶段继承

依据 20M 优化器/LR/MTP 和固定窗口对照，选定[工作参数](working-recipes.md)：Kimi/DeepSeek 全局 input 目标 32K，Qwen/MF1 为 16K。这里的 32K/16K 指 batch 目标。

显式 pretraining program 按参数名和算法契约继承优化器，indexer 阶段暂存冻结主干状态；主 CE、路由、QKClip、RNG 和兼容游标连续。小配置检查了 Kimi 分阶段/连续一致、Qwen/DeepSeek 跨 indexer 状态，以及 DeepSeek 收尾 MTP 0.3→0.1。

首批文本实际完成 374,806 条去重记录，训练 **369,181 条、458,020,690 参考 token**：中文 221,643,597、英文 147,701,678、数学 49,256,193、对话 39,419,222；val/test 为 1,801/3,824 条。每来源生成 100 条抽查材料。自然图片前 1,000 张已约 0.78GiB，需另建存储与缓存。

同期 MF1 packed 位置修复使固定文本完整更新短测提高 **17.52%**，条件与数值见上述性能审计。

### 文档/图表候选与代码补充

文档、图表在辅助工作站各构造 20K 张，任务预算 60GiB，其中元数据 3GiB；本地热缓存上限 25GiB。一次 60GiB 文件分配/回收检查确认当时空间可用。首次任务因继承失效代理在零图片时退出，改用直连后开始写入；seed 为 20260912，来源版本保持。

代码补充采用[CodeParrot 固定版本](https://huggingface.co/datasets/codeparrot/codeparrot-clean-train/tree/3e6ab65f2864931e041f6a82db9b5a6ec2b71ab4)。按[逐文件许可说明](https://huggingface.co/datasets/codeparrot/codeparrot-clean/discussions/1)核对 Apache-2.0、MIT、BSD-2/3-Clause 头，拒绝冲突许可、vendor/generated 和无法解析的 Python3。保留 repo/path、内容 SHA256、计算所得 Git blob SHA1、许可头与分片 hash；来源没有原仓库 commit。代码不执行、不折叠空白，近重复还要求 AST 一致。

目标 100M 参考 token，最多 500K 源行、3GiB 下载；目录 4GiB、单 gzip 临时文件 300MiB。代码路径 12 项、台账 10 项定向检查通过；完整 CPU **383 passed / 1 skipped**，54 项 CUDA 未运行。远端状态记录观察时间，超过 120 秒不沿用存活判断。

### 候选构造中断与保留进度恢复

代码在 **9,288 条、28,119,941 参考 token** 遇到超大 JSON 行；文档在 **244 张图、597 条 QA** 遇到 CDN 正文超时。恢复保留 SQLite、媒体与原计数，核对来源、seed、目标、tokenizer 及预算，并按原游标续读。

超过 2MiB 的源代码行整条跳过；单 gzip 解压上限 2GiB。HTTP 正文最多重试三次，重传继续扣网络预算。恢复后代码达到 **10,000 条、30,442,836 token**，超大行拒绝 1 条；文档达到 **250 张、608 条 QA**。详见[恢复快照](candidate-recovery.json)。完整 CPU **390 passed / 1 skipped**，54 项 CUDA 未运行；18 项恢复和 10 项后续锁回归通过。

实现版本：文档/图表 `9d3667f`，代码 `072ab73`，恢复 `642aced`，下载期间释放共享存储锁 `3c4bc39`。各次实际输入 hash 保存在原报告。

### 共享文本编码与 MF1 连续文档窗口

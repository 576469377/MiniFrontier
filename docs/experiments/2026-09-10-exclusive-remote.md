三条复现架构固定使用源码 `75a3364f586936d764c31376e185747973d2bed6`；MF1 固定使用 `d77c51c4ba074ba2d325f0b52e2ecceca392972e`。新调度器来自 `66a4ef1`。三模型保持原有 64K tokenizer、序列长度 512、全局输入批次 16384、单卡 microbatch 2、400K CE warmup 和 WSD 调度。原配方的 MTP 设置保持不变。

部署校验覆盖 201 个数据文件、约 2.34 GiB。迁移后的视觉记录只重定位资源路径并重建字节索引，保留原始清单及修改前后 SHA-256。文本 token、标签、样本身份、媒体内容和 tokenizer 不变；Kimi/Qwen 各自的训练及验证读图检查通过，并核对预编码 token 与标签。没有重新采样或重新训练 tokenizer。

两台机器使用相同的 PyTorch `2.13.0+cu130` 及复制的 Python 依赖环境。解释器分别为 Python 3.13.5 与 3.13.13，运行环境记录保留这个差异。跨主机的吞吐还会受到 CPU、频率和其他负载影响，不能仅凭首个更新声称单卡或异机更快。

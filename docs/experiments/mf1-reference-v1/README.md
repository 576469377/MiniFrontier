**数据更正：** fixture v1 的 val/test/demo 算术输入重复，三者不能作为独立泛化证据；训练算术与留出仍无重叠。修正版见[v2 档案](../mf1-reference-v2/README.md)。

## 实验条件与结果

2026-09-09，约 132K 参数的小配置、seed 42、CPU 两线程。训练集为 32 条算术、32 张色块图像、8 段色块视频；下表分开列出训练内生成、留出生成和媒体扰动检查。

| 项目 | 结果 |
|---|---|
| 训练量 / 耗时 | 9,404 CE、42,732 input，600 步约 239 秒 |
| 训练生成 | 算术 32/32、图像 32/32、视频 8/8 |
| 留出生成 | 算术 0/6、图像 4/4、视频 2/2 |
| 置黑媒体 | 图像 1/4、视频 0/2 |
| 视频倒序 / 重复首组 | 均为 1/2 |

完整 228.24M 结构另做了 CPU 随机图像前后向与缓存检查，与本页的小配置学习实验分别进行。

## 证据与复现

[报告](report.json)保存配置、文件校验值、梯度和限制，[CSV](overfit-curve.csv)保存 loss、梯度、token 与耗时。绘制学习曲线时，以 `step` 或累计 `ce_tokens` 为横轴、`train_lm_loss` 为纵轴；这条训练曲线应与报告中的留出生成结果分别阅读。

历史命令参数为 `mf1 train --phase pilot --steps 600 --input-batch-tokens 64 --lr 0.001 --vision-lr 0.001 --save-every 100 --eval-every 100`，tiny 配置与模型入门示例相同。权重和诊断图片不随源码分发。
